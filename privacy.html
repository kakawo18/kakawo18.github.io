プライバシーポリシー

youtube-uploader（以下「本ツール」）における情報の取り扱いについて定めます。

1. 本ツールの目的と利用者

本ツールは、運営者が制作した動画を運営者自身の YouTube チャンネルに投稿するための個人用ツールです。 利用者は運営者本人のみで、第三者に提供していません。

2. 取得・利用する情報

本ツールは、運営者本人の Google アカウントの認可により、YouTube Data API を通じて次の操作だけを行います。

  • 動画のアップロード（権限: youtube.upload）— 動画ファイル、タイトル、説明文、タグ、サムネイルの送信
  • チャンネル情報の読み取り（権限: youtube.readonly）— 接続確認のため、チャンネル名と動画数を表示

上記以外の Google アカウントの情報（メール、連絡先、視聴履歴など）は取得しません。

3. 情報の保存と管理

認可によって得られる認証情報（リフレッシュトークン等）は、運営者が管理する実行環境の設定にのみ保存し、 本ツールの目的以外には使用しません。取得した情報を第三者へ提供、販売、共有することはありません。

4. Google API サービスのユーザーデータに関するポリシー

本ツールによる Google API から受け取った情報の使用と他のアプリへの転送は、 Google API Services User Data Policy （Limited Use の要件を含む）に従います。 また、本ツールは YouTube 利用規約 と Google プライバシーポリシー に基づく YouTube API サービスを利用しています。

5. 認可の取り消し

本ツールへのアクセス許可は、Google アカウントのサードパーティ アクセス設定 からいつでも取り消せます。取り消すと、本ツールは YouTube へ投稿できなくなります。

6. 改定

本ポリシーを改定する場合は、このページを更新します。
